## Deliverable

`DFS_SYSTEM_GREENFIELD_SPEC_<YYYY-MM-DD>.md` at the repository root, dated the
day it is written. Four sections, as the audit mandate specified:

1. What the system is today, honestly. Working code separated from unverified
   claims, per `IMPLEMENTATION_STATUS.md`. Every current path still ends
   `MODEL_STATUS=PRIOR_ONLY` and `RELEASE_DECISION=DO_NOT_UPLOAD`, and the
   document says so without hedging.
2. What a greenfield build would do differently, and which of those differences
   are worth retrofitting against which are sunk.
3. The two objectives, stated so they cannot be silently traded: large-prize
   equity (first-place and upper-tail payout equity, appropriate to field size
   and payout structure) and portfolio survival (minimise washout while
   preserving tail equity). Name where the current engine serves one and not the
   other.
4. The findings, with their evidence and where each one landed.

## The subagent cost contract

Also in scope, and small. `CLAUDE.md` § Token discipline already names the two
subagents (`explorer` for more than five files, `reviewer` before close-out).
Write down what each one costs and what it may load: `tools:`, `model:`,
`omitClaudeMd: true` where the agent does not need the boundaries recited,
`maxTurns:`, preloaded `skills:`. A subagent that loads the full `CLAUDE.md` to
grep four files is the waste this contract exists to stop.

## Constraints

- **Never represent any implementation, backtest or simulation as a guarantee of
  profit or a known true winning probability.** This is the audit mandate's
  standing bound and it applies hardest to a document that summarises
  capability.
- Never call a prior EV, ROI, win probability, cash probability, calibrated
  ownership, or proven edge. `OPTIMAL` is scoped to the reported bank. Sample
  size is declared, not inferred.
- The report is a report. It changes no code, no contract, no gate.

## Acceptance

  each finding's disposition.
- `IMPLEMENTATION_STATUS.md` and the report do not disagree; if they do, the
  report is wrong and gets fixed.
- The subagent cost contract is written where a session will see it.
- Full suite green (the report should not change it, which is itself the check).
