# Session prompts (retired 2026-09-22)

Per-chunk paste prompts are retired. The Quick-Start in `docs/ROADMAP.md` §1 and
each session card in §2.3 replace them. The 22 earlier prompts are kept verbatim
in `archive/` as history; do not paste one into a new session.

Since 2026-10-08 the post-merge routine (`docs/claude/post_merge.md`) writes a
handoff prompt for the next session after each closing merge. It is derived from
the card by `scripts/next_prompt.py`, handed to Ben in chat, and never stored
here: this directory stays retired.
